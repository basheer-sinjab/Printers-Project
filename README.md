# دليل استخدام نظام إدارة الطابعات

## التشغيل عبر Docker

ثبّت Docker Desktop، ثم افتح الطرفية داخل مجلد المشروع ونفّذ:

```powershell
docker compose up -d --build
```

افتح النظام عبر `http://localhost:8080`. تحفظ قاعدة البيانات محلياً في مجلد `data` والصور المرفوعة في `uploads`؛ لا تحذف هذين المجلدين إذا كانت البيانات مهمة.

لإيقاف النظام:

```powershell
docker compose down
```

لرؤية سجل التشغيل عند حدوث مشكلة:

```powershell
docker compose logs -f
```

بعد فتح النظام ستجد كل ما يخص طابعات المؤسسة في مكان واحد: بيانات كل طابعة، موقعها، مسؤولها، سجل الصيانة، الأحبار، الموردون والتقارير. استخدم القائمة الجانبية للتنقل بين الأقسام.

## ابدأ من هنا

لإدخال بياناتك لأول مرة، اتبع هذا الترتيب:

1. افتح **الإعدادات** وأضف الفروع والأقسام والأشخاص المسؤولين.
2. أضف الموردين، ثم سجّل أصناف الأحبار وكمياتها الحالية.
3. انتقل إلى **الطابعات** وأضف طابعات المؤسسة واحدة تلو الأخرى.
4. سجّل أي صيانة أو تغيير حبر أو نقل من صفحة الطابعة نفسها.
5. راقب التنبيهات من **لوحة التحكم** واستخرج التقارير عند الحاجة.

## لوحة التحكم

لوحة التحكم هي الصفحة التي تفتح أولاً. تعرض ملخصاً سريعاً عن الأسطول:

- عدد الطابعات الكلي وحالتها الحالية: نشطة، تحت الصيانة، خارج الخدمة أو مؤرشفة.
- عدد أصناف الأحبار، والأحبار المنخفضة أو المنتهية.
- تنبيهات لنقص الحبر، وانتهاء الضمان أو قرب انتهائه.
- الطابعات التي وسمتها كمفضلة.
- آخر عمليات الصيانة وآخر عمليات تغيير الأحبار.

راجع هذه الصفحة باستمرار لتعرف ما يحتاج إلى إجراء قبل أن يؤثر على العمل.

## إدارة الطابعات

من صفحة **الطابعات** اضغط **إضافة طابعة** لتسجيل أصل جديد. أدخل الاسم ورقم الأصل وبقية البيانات المتاحة مثل الشركة المصنعة والموديل والرقم التسلسلي وعنوان IP وتاريخ انتهاء الضمان. يمكنك كذلك تحديد الفرع والقسم والشخص المسؤول وإرفاق صورة للطابعة.

تستطيع البحث بالاسم أو رقم الأصل أو الرقم التسلسلي أو عنوان IP أو الموديل. استخدم الفلاتر لتضييق القائمة حسب الفرع أو القسم أو الحالة أو الشركة المصنعة. اضغط على أي بطاقة لفتح صفحة الطابعة وتعديل بياناتها أو متابعة سجلها.

### صفحة الطابعة

صفحة الطابعة تجمع تفاصيلها وسجلها التشغيلي. استخدمها في الحالات التالية:

- عدّل الحالة عند توقف الطابعة أو إعادتها للخدمة أو أرشفتها.
- علّم الطابعة كمفضلة لتظهر في لوحة التحكم.
- حدّث بيانات الموقع أو الشبكة أو الضمان كلما تغيرت.
- افتح التبويب المناسب لتسجيل الصيانة أو تغيير الحبر أو النقل.

## تسجيل الصيانة

من صفحة الطابعة، افتح تبويب **الصيانة** ثم اضغط **إضافة صيانة**. اختر التاريخ ونوع الصيانة، واكتب وصفاً واضحاً للمشكلة أو العمل المنفذ وأضف اسم الفني.

عند استبدال قطعة، اخترها من مكتبة قطع الغيار أو أضفها مباشرةً إلى المكتبة. يبقى كل سجل محفوظاً في تاريخ الطابعة ويمكن تعديله أو حذفه لاحقاً.

## تغيير الأحبار

من تبويب **تغيير الأحبار** سجّل عملية الاستبدال وتاريخها، ثم اختر الحبر والكمية المستخدمة. إذا كان الحبر مسجلاً في المخزون، يخفض النظام كميته تلقائياً عند حفظ العملية.

يمكنك إدخال حبر غير مسجل في المخزون بالاختيار **حبر غير موجود بالمخزون** ثم كتابة اسمه. يفيد ذلك في توثيق الاستخدام من دون تعديل رصيد المخزون. أضف أكثر من صنف في العملية الواحدة عندما تستبدل عدة ألوان معاً.

## نقل الطابعة

عند تغيير موقع طابعة، افتح تبويب **النقل** واضغط **نقل الطابعة**. حدد التاريخ والفرع أو القسم أو المسؤول الجديد، ثم اكتب سبب النقل.

يحفظ النظام السجل القديم والجديد ويحدّث موقع الطابعة ومسؤولها الحالي تلقائياً.

## مخزون الأحبار

صفحة **مخزون الأحبار** مخصصة لتتبع رصيد كل صنف. عند إضافة حبر جديد، أدخل اسمه وكوده ولونه وكمية البداية والحد الأدنى للتنبيه، واختر المورد عند توفره.

لإضافة كمية وصلت حديثاً، استخدم زر إضافة الكمية بجانب الصنف. اكتب الكمية والتاريخ وأي ملاحظة، ثم احفظ. يظهر سجل آخر الإدخالات أسفل الجدول للرجوع إليه.

إذا أصبحت الكمية مساوية للحد الأدنى أو أقل منه، يظهر الصنف كمنخفض المخزون ويظهر تنبيه في لوحة التحكم.

## الموردون

من صفحة **الموردون** أضف اسم المورد وبيانات التواصل: المسؤول والهاتف والبريد الإلكتروني والملاحظات. بعد ربط المورد بأصناف الأحبار، يظهر عدد الأحبار المرتبطة به في قائمته، مما يسهل معرفة الجهة المناسبة عند طلب التوريد.

## الإعدادات

تحتوي **الإعدادات** على القوائم التي يعتمد عليها النظام:

- **الفروع:** مواقع المؤسسة أو مبانيها.
- **الأقسام:** الجهات أو الإدارات التي تستخدم الطابعات.
- **الأشخاص المسؤولون:** الموظفون المكلفون بكل طابعة.
- **قطع الغيار:** القطع التي تتكرر في أعمال الصيانة.
- **التنبيهات:** حد التنبيه الافتراضي لنقص الحبر وعدد الأيام قبل تنبيه انتهاء الضمان، مع خيار إظهار التنبيهات في لوحة التحكم أو إخفائها.

أضف هذه القوائم قبل إدخال الطابعات لتكون بياناتها موحدة وسهلة البحث.

## التقارير

افتح صفحة **التقارير** واختر ما تحتاجه من القائمة:

- تقرير الطابعات.
- تقرير مخزون الأحبار.
- تقرير الصيانة.
- تقرير استهلاك الأحبار.

يمكنك تقييد التقرير بفرع أو قسم، وإضافة فترة زمنية عند تقرير الصيانة أو الاستهلاك. بعد اختيار البيانات اضغط **طباعة / حفظ PDF** لطباعة التقرير أو حفظه كملف PDF من نافذة الطباعة.

## النسخ الاحتياطي والاستعادة

من **الإعدادات** افتح تبويب **النسخ الاحتياطي** ثم اختر **تنزيل نسخة احتياطية**. يتضمن الملف جميع بيانات النظام وصور الطابعات، لذلك احتفظ به في موقع آمن وبشكل دوري.

لاستعادة نسخة سابقة، اختر **استعادة نسخة** وحدد ملف النسخة الاحتياطية. الاستعادة تستبدل البيانات الموجودة حالياً؛ نزّل نسخة جديدة قبل الاستعادة إذا كانت البيانات الحالية مهمة.

## نصائح للاستخدام اليومي

- استخدم رقم أصل فريداً وواضحاً لكل طابعة لتسهيل البحث والجرد.
- حدّث حالة الطابعة فور توقفها أو إعادتها للخدمة كي تكون لوحة التحكم دقيقة.
- سجّل عمليات تغيير الحبر في وقتها حتى يبقى المخزون والتنبيهات صحيحين.
- اكتب وصفاً مختصراً ومحدداً في سجل الصيانة ليسهل فهم تاريخ الأعطال لاحقاً.
- أنشئ نسخة احتياطية قبل تحديث كبير في البيانات، وبشكل دوري حسب حجم العمل.
