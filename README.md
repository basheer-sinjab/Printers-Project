# نظام إدارة الطابعات — تشغيل محلي

يعمل المشروع محليًا بالكامل، دون Lovable أو Supabase أو تسجيل دخول. يستخدم ملف SQLite محليًا مشتركًا بين جميع المتصفحات التي تفتح نفس عنوان السيرفر.

## التشغيل

```bash
npm install
npm run dev
```

افتح الرابط الذي يظهر في الطرفية. التطبيق يفتح مباشرةً دون حسابات أو كلمات مرور.

## البيانات

تُحفظ الطابعات، الأحبار، السجلات والإعدادات في ملف SQLite محلي: `data/printers.db`. لذلك تظهر نفس البيانات في جميع المتصفحات التي تتصل بالسيرفر نفسه. لا تُرسل البيانات إلى أي خدمة خارجية.

تُحفظ صور الطابعات كملفات منفصلة داخل `uploads/printers` بجانب المشروع، وتحتفظ قاعدة البيانات بمسار الصورة فقط. من تبويب النسخ الاحتياطي في الإعدادات يمكن تنزيل أو استعادة نسخة تشمل البيانات والصور.

عند تشغيل النسخة الجديدة لأول مرة، تُرحّل بيانات IndexedDB القديمة تلقائيًا إلى SQLite إذا كانت القاعدة الجديدة فارغة. لا تحذف مجلد `data` أو `uploads` إذا أردت الاحتفاظ بالبيانات والصور.
